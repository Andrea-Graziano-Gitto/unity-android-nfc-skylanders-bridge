# Screenshots Guide

Place the following screenshot images in this directory to display them in the main `README.md`:

1. `app_ui.png` -> Screenshot of the Android App UI showing NFC status, Scan button, Form URL & Entry ID fields.
2. `google_form_setup.png` -> Screenshot of Google Form configuration (Field name, Get pre-filled link / entry ID).
3. `google_sheet_script.png` -> Screenshot of Google Sheets Extensions > Apps Script editor with the `gestisciInvioForm` code and trigger.
4. `dolphin_skylander_manager.png` -> Screenshot of Dolphin Emulator with the game running and the "Gestione Skylander" (Skylander Management) dialog open.
5. `demo.gif` -> (Optional) Short video/GIF showing figure tap on phone -> figure appearing in Dolphin.
